# Codex Windows x64 离线安装包（Base）

这是第三方整理的离线安装包，内含官方签名的 Codex Windows 桌面客户端、CC Switch 3.19.1 和微软 WebView2 Runtime；它不是 OpenAI 或 CC Switch 官方发行的组合包。

请将本文件夹与 `Friend-Codex-Windows-Offline-Runtime` 文件夹放在同一目录，然后双击 `START-WINDOWS.cmd`。安装过程不会临时访问 GitHub、Microsoft Store 或境外下载站。

本包不含 API Key，也不包含 Token 获取说明。安装结束后会打开 CC Switch，后续由你自己的 Agent 帮你配置兼容的 Endpoint、API Key 和模型。

完整离线能力需要同时提供 Runtime 包；缺少它时，文档、PDF、表格、演示及部分本地工具能力可能无法使用。
