# 发给 WorkBuddy 的安装配置提示词

先安装 WorkBuddy 或其他能操作本机的 Agent，把对应系统的安装包保存在电脑上，再复制下面的提示词。服务地址、可用模型和共享记忆初始文件由使用者提供；Key 在本地配置界面填写，不贴进 AI 聊天。

## 安装与配置

```text
帮我把刚收到的素材包装好并接入 API Key。我不熟悉电脑，请直接完成操作。
官方桌面客户端、CC Switch、runtime 和离线依赖都在包里。识别系统和芯片，找到对应包；找不到再问我。
Windows Codex 的主包和组件包都要解压，解压出的两个文件夹放在同一个父目录，从主包启动安装。已有可用的 Codex 就跳过 Codex 安装。
你可以开子代理并行，非必要不打断我，不要让多个代理同时改同一份配置。

【缺东西就自己装】
缺运行时、依赖、技能、插件，先复用已有能力，缺少的从官方来源补齐。
别改全局代理、防火墙和系统安全策略。官方安装需要管理员确认时提醒我，用当前桌面账户确认。
装完列个清单说明装了什么。

【第一步：体检加快照】
先检查影响安装的问题。退出待安装或待备份的 Claude / Codex 和 CC Switch，保留正在执行安装的 Agent，将 ~/.claude/、~/.claude.json、~/.codex/，以及当前系统的 Claude 桌面数据目录、CC Switch 数据目录，完整备份到桌面的 agent-backup-<日期>/，告诉我位置和大小。路径按系统实际解析，不存在的目录跳过。
本提示词明确要求的配置，备份后合并修改即可。整份覆盖配置、替换已有凭据、删除旧版应用或历史数据前先问我。

【第二步：装和配】
- CC Switch 按我提供的服务地址和 Key 配置，不要擅自换端点。缺地址或模型信息时集中问我。
- Key 通过本地配置界面由我填写，不要求我发进聊天，也不在输出中展示。
- 模型设成当前账号或 API 线路实际可用的最强那档模型。
- 权限设成免确认执行，常用命令批量加白名单；保留上一段要求的确认边界。
- 界面语言中文。
- 配好任务完成的声音或者系统通知。
- 装上文档处理技能，支持 Word、Excel、PPT、PDF 的读写；已有可用能力不重复装。
- 检查 Codex 插件市场，配置文档、表格、演示、GitHub 能力；需要账号授权时提醒我。
- 确认 gh 已认证；尚未认证时引导我完成本人账号授权，不冒用其他人的凭据。
- CC Switch 写完之后，检查原有 hooks、permissions、凭据段和其他线路有没有被覆盖。
最后必须在官方桌面应用里能用，终端 CLI 跑通不算。Claude 首次测试选 Code，本包不包含 Cowork 虚拟机。

【第三步：共享记忆】
1. 关闭各 Agent 可关闭的自动记忆功能，保留全局指令入口。没有关闭开关的直接报告，不编造设置。
2. 记忆和规则文档统一放在 ~/Documents/AgentOps/，初始文件由我提供；尚未收到就列为待提供。
3. 给各 Agent 挂入口指针，每次对话开始读取指定的主记忆文件：Claude Code 写进 ~/.claude/CLAUDE.md，Codex 写进 ~/.codex/AGENTS.md，其他 Agent 使用各自支持的全局指令入口。保留原有规则。
4. 配双云备份：Git 私有仓库，再加飞书云文档或已配置云同步的 Obsidian 库。使用我自己的账号，提交前检查，不带 Key、token 或不应上传的隐私信息。

【第四步：验收】
1. 在 Claude / Codex 桌面应用里分别发起真实请求，说明实际服务和模型，不展示 Key。
2. 网页搜索加网页抓取。
3. 浏览器面板打开网页并截图。
4. 读一张截图，确认能描述图片内容。
5. 打开安装前存在的历史对话，确认仍可读取。
6. 用文档能力读取或生成 Word / Excel 文件。
7. 建一个每月审计共享记忆文档的定时任务，并触发一次测试。
8. 通知实际弹出或响铃。
9. 各 Agent 新开一次对话，询问用户偏好，核对确实读取了主记忆文件。
10. 复制 AgentOps 到临时测试目录，改坏副本里的一个文件，从云端恢复并比较内容，不动正式文件。
11. 列出最终注册的 MCP server 清单。

每项写通过、未完成或不适用。未完成写具体报错和可能原因；不适用说明前提，例如新电脑没有历史，或当前平台不支持某项能力。
最后将 11 项整理成简短清单，说明安装了什么、备份在哪里，以及以后从哪里打开应用和切换线路。
```

## 装好后的工作流适配

思考与方案用强模型，审核优先换另一家厂商；无法跨厂时用独立上下文并注明。执行用适合任务的中档模型，批量扫描等机械工作可以用便宜快模型并行。具体型号按当前平台可用情况选择。

```text
请先浏览我提供的开源仓库列表，读各项目简介，再完整阅读与我工作相关的仓库。
如果我尚未给出列表，先问我，不自行假设我要照搬谁的工作方式。

可以开多个子代理，用便宜快模型整理过去一个月与各个 AI 的对话记录。先说明实际可读取的平台和日期范围，读不到的列出来，不把部分记录说成全部。

由强模型判断我的实际工作中哪些适合采用这些仓库的做法，写一份适配我电脑和需求的方案，不照搬。指出哪些工作可交给 Agent，哪些适合写程序自动化。

按优先级排序，并执行所选仓库的会审流程；优先使用另一家厂商的模型独立审核。若没有可用流程或缺少审查能力，说明情况，不声称已完成会审。
我确认方案后再执行。
```
